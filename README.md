# Portfólio | Carolina Passoni Pereira

Site pessoal estático com projetos de software, inteligência artificial, educação tecnológica, experiências e formações.

## Como executar

Abra `index.html` no navegador por um servidor estático local. Por exemplo:

```sh
python -m http.server 8000
```

Acesse http://localhost:8000.

## Publicação na Vercel

Framework: Other (site estático). Diretório raiz: `/`. Não é necessário comando de build.

## Arquivos

- `index.html`: conteúdo e estrutura da página
- `styles.css`: design responsivo
- `script.js`: menu, filtros, animações e botão de copiar e-mail
- `assets/`: favicon e currículo em PDF

## Segurança e créditos

Este repositório contém apenas os arquivos públicos do site, sem códigos privados dos sistemas citados, tokens, certificados digitais ou credenciais. As ilustrações das aplicações são conceituais. O conteúdo dos projetos foi descrito com base nos materiais fornecidos pela autora.
